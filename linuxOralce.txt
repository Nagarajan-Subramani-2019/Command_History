Your Windows C: drive is /dev/nvme0n1p3. We can try accessing it read-only using Dislocker and the stored unlock key from its protection-off state. Dislocker instructions
Run these on Linux, one command at a time. If any command fails, stop and send the error.
1. Install the tools:
   sudo dnf install -y oracle-epel-release-el10
   sudo dnf install -y fuse-dislocker ntfs-3g
2. Create the mount folders:
   sudo mkdir -p /mnt/windows-bitlocker /mnt/windows
3. Open the encrypted partition read-only:
   sudo dislocker-fuse -r -V /dev/nvme0n1p3 -c -- /mnt/windows-bitlocker
4. Mount its Windows filesystem read-only:
   sudo mount -t ntfs-3g -o "ro,loop,uid=$(id -u),gid=$(id -g),umask=077" /mnt/windows-bitlocker/dislocker-file /mnt/windows
5. Open Files, press Ctrl + L, and enter:
   /mnt/windows
You should see the contents of C:. Your Windows account’s files will normally be under Users → Admin. You can copy files into Linux; this setup keeps the Windows files read-only.
Before restarting, close files opened there and run:
sudo umount /mnt/windows
sudo umount /mnt/windows-bitlocker
