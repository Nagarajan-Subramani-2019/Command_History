For Oracle Linux 10.2 x86_64, install Python 3.15.0, the latest stable release, from source.
Run these blocks on your Linux machine, stopping if a command fails.
1. Install build dependencies:
sudo dnf install -y gcc make pkgconf-pkg-config tar gzip \
  openssl-devel bzip2-devel libffi-devel zlib-ng-compat-devel \
  xz-devel readline-devel sqlite-devel libzstd-devel
2. Download, build, and install:
mkdir -p ~/python-build
cd ~/python-build

curl -fLO https://www.python.org/ftp/python/3.15.0/Python-3.15.0.tgz

echo "438596cac081036d3c1d532ab7e7335eeb35567bc961749a0d5797176db0db68  Python-3.15.0.tgz" \
  | sha256sum -c -

tar -xzf Python-3.15.0.tgz
cd Python-3.15.0

./configure --prefix=/opt/python-3.15 --with-ensurepip=install
make -j2
sudo make altinstall
This installs a separate Python executable. Python recommends altinstall to preserve the system’s python3 command. Python installation documentation
3. Verify and create your working environment:
/opt/python-3.15/bin/python3.15 --version
/opt/python-3.15/bin/python3.15 -m pip --version

/opt/python-3.15/bin/python3.15 -m venv ~/venvs/py315
source ~/venvs/py315/bin/activate

python --version
The final command should show Python 3.15.0.
